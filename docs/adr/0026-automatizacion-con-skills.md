# ADR-0026 — Automatización de módulos con skills

- **Estado:** Aceptada
- **Fecha:** 2026-08-06
- **Fuente:** `docs/00-Plan-inicial.md` §3 (tabla ADR-lite, decisión D26)

## Decisión

**Se elige:** Una sola skill, `/quini-api-new`, prevista para escribirse después de tener un módulo terminado a mano

Una skill que "sigue los patrones del proyecto" necesita que esos patrones ya existan. Escrita al principio codificaría una propuesta hipotética; escrita después del patrón rodado a mano codifica código real y lecciones aprendidas de verdad.

## Alternativas consideradas

- Escribirla al principio del proyecto
- escribir de golpe `new`/`update`/`delete`
- no automatizar nada

## Consecuencias

No llegó a implementarse (ver cronología del proyecto, columna "Alcance decidido, no pendiente").
